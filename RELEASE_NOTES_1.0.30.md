# Safeer Linux 1.0.30

**Open PDF files from your computer, and clearer Safeer Link wording.**

- A PDF on your disk now opens in Safeer's built-in viewer: choose "Open with Safeer Browser" in the file manager, or type its `file://` address. Only existing `.pdf` files are allowed this way; other local files stay closed, as before.
- Safeer Link no longer talks about a "hub". Start on whichever device is at hand, the others join it; the pairing code is typed on the joining device.

Slovensko: PDF z diska se zdaj odpre v vgrajenem pregledovalniku Safeerja – v upravitelju datotek izberi »Odpri z Safeer Browser« ali vtipkaj naslov `file://`. Tako se odprejo samo obstoječe datoteke `.pdf`; druge lokalne datoteke ostanejo zaprte kot doslej. Safeer Link ne govori več o »središču«: povezovanje začneš na napravi, ki jo imaš pri roki, ostale se ji pridružijo; kodo vtipkaš na napravi, ki se pridružuje.

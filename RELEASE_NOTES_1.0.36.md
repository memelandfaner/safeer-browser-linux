# Safeer Linux 1.0.36

**The browser speaks your language, and the project is now open for everyone to read.**

- **Settings in your language.** The settings window, its dialogs and the messages that follow them (default browser, appearance and text size, on-screen keyboard, filtering, user scripts) now follow the system language in English, Slovenian, German, Spanish, French and Italian. Until now parts of the interface stayed in Slovenian whatever language the computer used.
- **The home page follows the same language** as the rest of the browser, English by default.
- **The project is public.** The repository now carries an English README with the current release and install command, a contributing guide and a code of conduct, so anyone can read the code and report a problem.
- Safeer Control is unchanged in this release (package **safeer-control** 2.0.2).
- Safeer Browser has no other functional changes; filtering, Safeer Link and the interface work as in 1.0.35.

Slovensko: **nastavitve govorijo tvoj jezik.** Okno z nastavitvami, njegova pogovorna okna in sporočila (privzeti brskalnik, videz in velikost pisave, zaslonska tipkovnica, filtriranje, uporabniške skripte) se zdaj ravnajo po jeziku sistema v angleščini, slovenščini, nemščini, španščini, francoščini in italijanščini; doslej je del vmesnika ostal slovenski ne glede na jezik računalnika. **Domača stran** govori isti jezik kot brskalnik, privzeto angleško. **Projekt je javen:** repozitorij ima angleški README z zadnjo izdajo in ukazom za namestitev, navodila za sodelovanje in kodeks vedenja. Safeer Control je v tej izdaji nespremenjen (paket **safeer-control** 2.0.2), drugih funkcionalnih sprememb v brskalniku ni.

# Safeer Linux 1.0.27

**Safeer Link: the computer now receives as well as sends — and no TV is required.**

- Any device can be the hub (phone, computer or TV). When the TV is off, the computer finds another hub on the network by itself; if it was already paired with it, it connects without a new code. Pairings with several hubs are remembered by each hub's key.
- The computer sends text, files and its screen to any device, and receives pages, text, files and screens from any device — also in the background, while you browse: a page opens in a new tab, text in a small window (copy / open link), a file lands in your downloads folder, another device's screen opens as a tab.
- All connections between devices are encrypted (TLS) and bound to the hub's key; the 6-digit pairing code never travels over the network (SPAKE2). Devices running an older version cannot pair with a new hub — update all of them together.
- The DNS-over-HTTPS proxy no longer refuses private network addresses, so pages served by your own devices (the screen viewer) open correctly.
- The Safeer Link page is the same on the computer, phone and TV.

Slovensko: Safeer Link brez televizorja — središče je lahko katerakoli naprava (telefon, računalnik ali televizor). Ko televizor ugasne, računalnik sam poišče drugo središče; če je bil z njim že seznanjen, se poveže brez nove kode. Računalnik pošilja besedilo, datoteke in svoj zaslon ter sprejema strani, besedila, datoteke in zaslone z drugih naprav — tudi v ozadju, med brskanjem: stran se odpre v novem zavihku, besedilo v oknu (Kopiraj / Odpri), datoteka pristane v mapi prenosov, zaslon druge naprave se odpre kot zavihek. Vse povezave so šifrirane (TLS) in vezane na ključ središča; 6-mestna koda nikoli ne potuje po omrežju (SPAKE2). Naprave s starejšo različico se z novim središčem ne morejo seznaniti — posodobi vse hkrati. Posrednik DNS prek HTTPS ne zavrača več zasebnih naslovov v omrežju.

# Safeer Linux 1.0.33

**Safeer Link polish — and Safeer Control 2.0 as a standalone desktop app.**

- The remote says which device is the Safeer Link hub and whose apps it lists; the Menu key opens the menu on the TV or phone and the remote's keys then move inside that menu.
- The home page is no longer offered for sending; a refused action no longer colours the whole window yellow.
- A pairing the hub no longer knows (the TV was reset or removed this computer) leads to a new pairing with a code instead of endless "Connecting …"; the Safeer Link window shows the right state the moment it opens.
- New package **safeer-control** (2.0.0): Safeer Control as its own desktop app with Safeer Link built in — the remote for your TV and phone, sharing of screen, files and text — no browser required. If Safeer Browser on this computer is already in Safeer Link, Control takes over that pairing without a new code.

Slovensko: Daljinec pove, katera naprava je središče Safeer Linka in čigave aplikacije kaže; tipka Meni odpre meni na televizorju ali telefonu, tipke daljinca pa se nato premikajo po njem. Domače strani ne ponujamo več za pošiljanje; zavrnjeno dejanje ne obarva več celega okna. Seznanitev, ki je središče ne pozna več (televizor je bil ponastavljen ali je računalnik odstranil), vodi v novo seznanitev s kodo namesto v večno »Povezujem …«; okno Safeer Link pokaže pravo stanje takoj ob odprtju. Nov paket **safeer-control** (2.0.0): Safeer Control kot samostojna namizna aplikacija z vgrajenim Safeer Linkom – daljinec za televizor in telefon, deljenje zaslona, datotek in besedila – brez brskalnika. Če je Safeer Browser na tem računalniku že v Safeer Linku, Control to seznanitev prevzame brez nove kode.

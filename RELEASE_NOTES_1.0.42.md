# Safeer Linux 1.0.42

**Sound over HDMI works again after using Safeer Link: no more leftover "Safeer-TV" outputs.**

- **No leftover sound outputs (Safeer Control 2.0.8).** Programs you start from the TV play their sound on a virtual output called Safeer-TV. It used to be removed only when Safeer Control quit cleanly; after an update, a crash or a restart it stayed behind, and every new start added another one. With several of them in the list of sound devices, sound would not play over HDMI any more until the computer was restarted. Safeer Control now removes all its leftover outputs when it starts, before it creates a new one and when it stops. Your own sound devices are never touched.
- **Safeer-TV only while it is needed.** The virtual output now appears only while a program started from the TV is running on the separate screen. A few seconds after the session ends and the programs are closed, it disappears from your sound devices, and it comes back with the next session. If a program stays open (for example in the Continue row), the output stays too, so its sound never suddenly jumps to your computer's speakers. Your default sound output stays as it was.
- Safeer Browser has no functional changes in this release.

Slovensko: **zvok po HDMI spet deluje tudi po uporabi Safeer Linka – izhodov »Safeer-TV« ne ostaja več.** Programi, ki jih zaženeš s televizorja, igrajo na navidezni izhod Safeer-TV. Prej se je odstranil samo ob čistem izhodu iz Safeer Controla; po posodobitvi, sesutju ali ponovnem zagonu je ostal, vsak nov zagon pa je dodal še enega. Ko se jih je nabralo več, zvok po HDMI ni več deloval do ponovnega zagona računalnika. Safeer Control 2.0.8 ob zagonu, pred ustvarjanjem novega in ob ustavitvi odstrani vse svoje ostale izhode; tvojih zvočnih naprav se ne dotika. **Safeer-TV samo, ko je potreben:** izhod se pokaže samo, dokler na ločenem zaslonu teče program s televizorja. Nekaj sekund po koncu seje, ko so programi zaprti, izgine iz zvočnih naprav in se ob naslednji seji vrne. Če program ostane odprt (npr. v vrstici Nadaljuj), ostane tudi izhod, da njegov zvok ne skoči nenadoma na zvočnike računalnika. Privzeti izhod ostane, kakršen je bil. Brskalnik Safeer v tej izdaji nima funkcionalnih sprememb.

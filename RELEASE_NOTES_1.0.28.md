# Safeer Linux 1.0.28

**The built-in PDF viewer now speaks Safeer's language, and a PDF tab has a name.**

- The PDF viewer (reading, search, highlighting, text, drawing, images, saving) took its language from the system, not from the browser's own language setting. It now follows the language you chose in Safeer, like the rest of the interface.
- A tab showing a PDF used to be called "New page". It now shows the file name (from the server's file name or the address) with a 📄 icon.

Slovensko: Vgrajeni pregledovalnik PDF (branje, iskanje, označevanje, besedilo, risanje, slike, shranjevanje) je jezik vzel iz sistema, ne iz nastavitve jezika v Safeerju — zdaj sledi jeziku, ki ga izbereš v brskalniku. Zavihek s PDF-jem se je imenoval »Nova stran«; zdaj kaže ime datoteke z ikono 📄.
